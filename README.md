# Banana Planet

This repository is the shared home for the Banana Planet iPhone game project.

## How to use this project

- Describe the game idea or a change in plain language.
- Codex can create and update the project files.
- Unity-ready work will go in the `Unity/` folder.
- Project decisions and instructions for other AI collaborators live in `docs/`.

## Project status

This is the starter repository. The game design, art direction, and first playable scene will be added next.

## Collaboration

Keep the repository private while the project is in development. Invite trusted people or connect other AI tools that you choose to use. Never save passwords, API keys, or other secrets in this repository.
