# Banana Planet collaboration guide

## Purpose

This file helps people and AI assistants work from the same understanding of the project.

## Working agreement

1. Read `README.md` and this file before proposing a change.
2. Explain suggestions in plain language.
3. Keep each change small and clearly describe what it does.
4. Do not add private information, passwords, API keys, or credentials to the repository.
5. Record important creative and technical choices in this document.

## Current decisions

- Game engine target: Unity
- Target platform: iPhone
- Repository privacy: private
- Primary collaboration style: plain-language requests, with Codex preparing project files
